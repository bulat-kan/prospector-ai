# DESIGN PRINCIPLES

# Product Philosophy

Prospector AI is a Field Sales Operating System, not a CRM.

# Core Principles

-   Mobile-first
-   30-second interaction rule
-   Activities are the heartbeat
-   Protect Golden Time
-   Plan tomorrow today
-   AI assists; it never interrupts
-   Enter data once
-   Salesforce is the system of record
-   Prospector AI is the system of execution
-   Behaviors drive results

# UI Rules

-   Large touch targets
-   Single-column phone layouts
-   Progressive disclosure
-   Quick actions always visible
-   Voice-first ready
-   Minimal typing
-   Cards over tables for daily work

# Development Rules

-   Business logic outside UI
-   Shared validation/constants
-   API-ready services
-   Test every feature
-   Cost-aware AI
